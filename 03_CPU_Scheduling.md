Process Management

Definition
A process is a program currently under execution.

Process States
1. New
2. Ready
3. Running
4. Waiting
5. Terminated

Process Control Block (PCB)
PCB stores:
- Process ID
- Process state
- Program counter
- CPU registers
- Scheduling information
- Memory information
- I/O information

Process Scheduling
The operating system selects processes from the ready queue for CPU execution.

Context Switching
Context switching is the process of saving the current process state and loading another process state.

Threads
A thread is the smallest unit of CPU execution within a process. Multiple threads can share resources within the same process.

Conclusion
Process management enables multitasking and efficient CPU utilization.
