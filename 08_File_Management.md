File Management and OS Security

File Management

The operating system manages file creation, deletion, storage, retrieval, and access permissions.

File Allocation Methods

1. Contiguous Allocation
Files are stored in consecutive disk blocks.

2. Linked Allocation
Each file block contains a pointer to the next block.

3. Indexed Allocation
An index block stores the addresses of file blocks.

OS Security
Operating-system security protects data and system resources against unauthorized access.

Security Mechanisms
- Authentication
- Authorization
- Encryption
- Access Control
- Auditing

Access Matrix
An access matrix defines the permissions of subjects over objects.

Example permissions:
- Read
- Write
- Execute

Security Principles
- Least Privilege
- User Authentication
- Data Confidentiality
- Data Integrity
- Availability

Conclusion
File management organizes stored information, while security mechanisms protect system resources and user data.
