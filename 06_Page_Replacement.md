Page Replacement Algorithms

Definition
Page replacement algorithms determine which memory page should be removed when a new page must be loaded and no free frame is available.

Algorithms

FIFO
First In First Out replaces the page that entered memory earliest.

LRU
Least Recently Used replaces the page that has not been used for the longest time.

Optimal
Optimal replacement removes the page whose next use is farthest in the future.

Comparison

| Algorithm | Replacement Basis |
| FIFO | Oldest loaded page |
| LRU | Least recently used |
| Optimal | Farthest future use |

Conclusion
Page replacement algorithms help manage limited physical memory and reduce page faults.
