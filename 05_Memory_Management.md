Memory Management:

Definition
Memory management controls the allocation and deallocation of main memory.

Contiguous Memory Allocation
A process is allocated a continuous block of memory.

Methods:
- First Fit
- Best Fit
- Worst Fit

Paging
Paging divides logical memory into fixed-size pages and physical memory into frames.

Advantages:
- Eliminates external fragmentation.
- Supports virtual memory.
- Simplifies memory allocation.

Segmentation
Segmentation divides a program into variable-sized logical sections.

Examples:
- Code segment
- Data segment
- Stack segment

Virtual Memory
Virtual memory allows programs to execute without loading the entire program into physical memory.

Page Fault
A page fault occurs when a requested page is not available in main memory.

Conclusion
Memory management improves memory utilization and supports efficient program execution.
